Data123 | SQL Server MES dashboard prototype

Install Python 3.11+ and Microsoft ODBC Driver 18 for SQL Server. Run run.bat on an authorized Windows PC. Enter connection details locally. Default SQL Server port 1433. Use an account restricted to SELECT; application issues SELECT queries only. Encryption enabled, certificate validation on by default. Only relax validation with IT approval. Select table and date. Native SQL Server datetime columns supported. Production day 06:00–06:00. Counts use first event per unique module per day. Lamination is entry count. Confirm rejection codes and reconcile all KPIs before official use. Not tested against live MES. Localhost only; no credentials or records in Git.
